Lof Library 서재 동기화 서버
확인 중

개요

Lof Writer가 이 PC의 서버로 원고를 동기화합니다.

서버를 실행하지 못했습니다

접속 주소

Lof Writer에서 서버를 연결할 때 사용합니다. 다른 기기는 같은 네트워크의 주소로 접속합니다.

    서재

    서버에 보관한 서재와 이력 규칙을 관리합니다. 작품과 원고는 연결한 Lof Writer에서 편집합니다.

    서재를 관리하려면 서버를 시작해 주세요.

      아직 서재가 없습니다

      서재 만들기로 추가하거나, Lof Writer에서 서버를 연결하며 만들 수 있습니다.

      연결 기기

      연결 코드로 등록한 기기입니다. 연결을 해제하면 해당 기기는 즉시 동기화할 수 없습니다.

        아직 연결한 기기가 없습니다

        기기 추가에서 연결 코드를 발급한 뒤 Lof Writer의 서버 연결 화면에 입력해 주세요.

        설정

        네트워크와 실행 방식을 바꿉니다.

        네트워크

        포트바꾸면 서버를 다시 시작합니다. 연결된 기기의 서버 주소도 함께 바꿔야 합니다.

        실행

        업데이트

        버전 확인 중새 버전을 자동으로 확인합니다.

        데이터

        데이터 폴더
        서버 로그문제가 생겼을 때 원인을 확인합니다.

        기기 추가

        연결 코드를 발급하고 있습니다…

        Lof Writer의 설정 → 외부 저장소에서 ‘Lof Library 서버’를 고른 뒤 연결 정보를 붙여넣어 주세요.

        다른 기기에서 접속하려면 설정에서 ‘다른 기기에서 접속 허용’을 켜 주세요.

        이제 이 기기에서 원고를 동기화할 수 있습니다.

        서재 만들기

        이 서재는 연결한 Lof Writer에서 선택할 수 있습니다.

        이력 설정

        자동 기록

        이전 기록 이후 아래 두 조건을 모두 만족하면 이력을 만듭니다. 원고 동기화는 이 조건을 기다리지 않습니다.

        보관 기간

        자동 삭제를 끄면 기간 제한 없이 보관합니다. 문서별 최신 이력은 유지합니다.

        스마트 정리

        최근 이력은 모두 보관하고, 그보다 오래된 자동 이력은 각 구간의 마지막 기록만 남깁니다. 수동·복원 기록은 스마트 정리에서 보호합니다.

        이 서버 서재에 공통으로 적용합니다. 정리된 과거 이력은 되돌릴 수 없습니다.

        서버 서재 삭제

        서버에 있는 이 서재의 문서·첨부 자료·변경 이력·충돌 사본을 영구 삭제합니다. 연결한 Writer의 로컬 원고는 남지만, 이 서버 서재와는 더 이상 동기화할 수 없습니다.
