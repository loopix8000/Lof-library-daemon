# Lof Library Daemon

Lof Writer의 서재를 여러 기기에서 동기화하기 위한 개인용 중앙 서버입니다.
PC나 NAS에 설치하고, 연결된 Lof Writer 앱의 변경 사항을 실시간으로 전달하는 것을 목표로 합니다.

현재는 기획 단계이며, 동기화 서버와 앱 연동은 아직 구현하지 않았습니다.

## 목표

- **실시간 동기화**: 앱에서 저장한 변경을 서버가 받아 다른 연결 기기에 알립니다.
- **변경분 전송**: 변경된 문서와 필요한 자료만 주고받고, 같은 내용을 반복 전송하지 않습니다.
- **중앙 이력 관리**: 서버에서 원고의 변경 이력을 보관하고 이전 버전을 조회·복원합니다.
- **충돌 보존**: 여러 기기에서 같은 문서를 수정하면 내용을 덮어쓰지 않고 충돌을 확인할 수 있게 합니다.
- **오프라인 복귀**: 연결이 끊긴 동안의 로컬 편집을 보존하고 재연결 시 서버 변경과 함께 반영합니다.

## 동작 구상

1. Lof Writer 앱이 서버에 인증하고 서재를 연결합니다.
2. 앱이 저장된 변경을 전송하면 서버가 버전을 확인하고 원고와 이력을 기록합니다.
3. 서버가 다른 연결 기기에 변경을 알리고, 해당 앱이 필요한 변경분을 받습니다.
4. 재연결한 기기는 마지막으로 반영한 지점 이후의 변경을 확인합니다.

## 배포 방향

- Docker 이미지와 Docker Compose 구성으로 배포합니다.
- 원고·첨부 자료·변경 이력은 영구 볼륨에 보관합니다.
- NAS와 개인 서버에서 직접 운영할 수 있도록 가볍게 구성합니다.

통신 규약, 저장 형식, 이력 보관 정책과 Lof Writer 연동 방식은 구현 단계에서 정합니다.
